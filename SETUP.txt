GolfDeck setup
==============

1. Download GolfDeck.exe and put it anywhere (e.g. C:\GolfDeck).
2. Run it. Windows SmartScreen may warn about an unknown publisher the
   first time: click "More info", then "Run anyway". (Or right-click the
   exe, Properties, tick Unblock, OK.)
3. Pick your board layout:
   - V1 : PUTT top-left (PUTT / HEATMAP / FLYOVER / SHOTCAM top row)
   - V2 : SCORECARD top-left (SCORECARD / FAST FWD / HEATMAP / HIDE OBJECT)
   A mapping.txt with the correct GSPro keys for that layout is created
   automatically next to the exe.
4. Plug in the golf controller. Buttons light up in the window when pressed.
   You can also click the on-screen buttons with the mouse to test keys.
5. Tick "Start with Windows" to auto-start minimized to the tray.
6. If GSPro runs as administrator, use the tray icon menu
   "Restart as administrator" once.

Options button
--------------
- Board layout: V1 / V2 (offers to load that layout's default GSPro mapping)
- Input device: Auto, or pick a specific controller / joystick
- Input monitor: shows live which button number and axis your box reports
- Edition presets: Original, Green Jacket, Red & White, Red White & Blue
- Board / Button / Letters colours individually
- Load defaults: rewrites mapping.txt for the current board and device
- Check for updates

Wired and wireless boxes
------------------------
Both work. Wireless units are Xbox-compatible; wired units show up as
"Generic USB Joystick". GolfDeck detects which one is plugged in and uses
the matching key mapping - if you swap one for the other it will notice and
offer to load the right defaults.

If the buttons do the wrong things, open Options > Input monitor, press each
button on the box, note the Btn number it reports, and put those numbers into
mapping.txt (Options > Edit mapping).

Updates
-------
GolfDeck checks GitHub for new releases on launch and offers to update
itself. Declining waits 7 days before asking again; check manually any time
from Options.

Key send modes
--------------
- Virtual keys : normal Windows key injection. Default, try first.
- Scancodes    : alternate injection flavor. Try if GSPro ignores keys that
                 Notepad receives.

Mapping
-------
mapping.txt holds all bindings (button = key | label | mode). Edit with the
"Edit mapping" button, apply with "Reload mapping". The board GUI attaches
mappings by label, so if a physical button lights the wrong spot, swap the
labels in mapping.txt.
